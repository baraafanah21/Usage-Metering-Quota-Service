How this demo works
  • This page talks only to the demo server. The demo server holds DocuCorp's API key and calls the metering API, so no API key reaches the browser. The request JSON shown here names the key header, never the key.
  • The demo server also holds the operator (admin) key, because it plays the operator who creates accounts. A real client app would only have its own account's API key.
  • Free play uses DocuCorp (Demo Team: 60 a month, max 50 per request; alice and carol on Basic, bob on Premium). The guided scenario creates a fresh account each run, so its result doesn't depend on free play.
  • "Retry" sends the same requestId again: you get the stored decision, nothing is counted twice.
  • Reset everything with docker compose down -v.
